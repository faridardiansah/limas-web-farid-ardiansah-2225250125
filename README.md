# Dokumentasi Proyek — Aplikasi Pembelajaran Bangun Ruang Limas

Dokumentasi awal sebelum implementasi aplikasi web pembelajaran matematika untuk siswa SMP kelas IX. Aplikasi dirancang responsif dan mengutamakan penggunaan melalui smartphone Android.

## Status dokumen
Dokumen ini merupakan rancangan awal berdasarkan wawancara dua siswa, bukan spesifikasi final yang sudah diuji ke seluruh calon pengguna. Detail teknis dapat disesuaikan sebelum coding.

## Dasar analisis
Sumber utama: *Hasil Wawancara Analisis Kesulitan Belajar Materi Bangun Ruang Limas*, Farid Ardiansah, 11 halaman, wawancara 8 November 2026. Informan: S01 (Pujaroh) dan S02 (Aldiyansah), siswa kelas IX SMPN 1 Gunungsari.

## Prinsip penting
- Mobile-first: nyaman digunakan pada layar smartphone Android.
- Bahasa Indonesia yang sederhana dan sesuai tingkat SMP.
- Materi disajikan bertahap, tidak menumpuk terlalu banyak informasi pada satu layar.
- Bedakan secara visual tinggi limas dan tinggi sisi tegak.
- Aplikasi web dapat dibuka melalui browser; instalasi aplikasi Android native bukan kebutuhan tahap awal.
- Jangan menganggap fitur 3D wajib tersedia pada versi pertama; mulai dari ilustrasi interaktif yang jelas, lalu evaluasi kebutuhan 3D.
