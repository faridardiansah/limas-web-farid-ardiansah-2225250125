# Roadmap Pengembangan

## Tahap 0 — Validasi kebutuhan
- Konfirmasi target kelas dan cakupan materi.
- Periksa kembali hasil wawancara dan bedakan jawaban informan dari interpretasi penulis.
- Minta guru/dosen memeriksa ketepatan konsep dan rumus.
- Tentukan apakah aplikasi perlu menyimpan progres.

## Tahap 1 — Desain
- Buat wireframe beranda.
- Buat wireframe halaman unsur limas.
- Buat diagram perbedaan dua jenis tinggi.
- Buat wireframe rumus, contoh soal, dan latihan.
- Uji prototipe sederhana pada beberapa siswa.

## Tahap 2 — MVP frontend
- Inisialisasi proyek React + TypeScript + Vite.
- Buat layout mobile-first dan navigasi.
- Implementasikan materi dan diagram SVG.
- Implementasikan rumus dan contoh soal.
- Implementasikan kuis, umpan balik, dan skor.
- Simpan progres lokal bila diperlukan.

## Tahap 3 — Pengujian
- Uji fungsi navigasi, kuis, dan perhitungan.
- Uji responsivitas Android.
- Uji keterbacaan dan pemahaman dengan siswa.
- Perbaiki bagian yang masih membingungkan.

## Tahap 4 — Deployment
- Push source ke GitHub.
- Deploy ke Cloudflare Pages/Vercel/Netlify.
- Uji URL publik pada perangkat Android.
- Catat versi dan perubahan.

## Tahap 5 — Pengembangan lanjutan
- Evaluasi kebutuhan 3D.
- Pertimbangkan PWA/offline.
- Tambahkan backend hanya jika ada kebutuhan akun, sinkronisasi, atau panel guru.
